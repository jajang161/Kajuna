# What If Labs — visual style reference guide

This fork extends Bang Motion's README with **ten What If Labs visual concept previews**, while retaining every upstream style and script. These are original static SVG reference artworks **not** implemented Bang Motion rendering presets or ready-made animated scenes.

## Cinematic production requirement
These SVG gallery previews are **references, not acceptable final flat-card video frames** for What If Labs. Prefer photorealistic / science-accurate 3D and meaningful camera depth, using diagrams only as a supporting layer. See `docs/what-if-labs-cinematic-3d-standard.md`. The goal is an eye-catching coherent documentary, not a children's flashcard or a fixed animation template.

## Storyboard usage

Design each short around a concrete question, one testable or clearly hypothetical mechanism, and a concluding insight. For a 30-second episode, the current preferred structure is **three clips of 10 seconds** with **four distinct scenes per clip** (12 scenes overall). Keep the English CapCut voiceover separate from the video prompts, provide an Indonesian translation, and synchronize the narrative with visual changes.

The style is a visual *language*, not a fixed episode formula. Vary shot sizes, geography, category, and visual approach to avoid repetitive or mass-produced results.

## Gallery style catalog

| Style | Visual grammar | Good for |
| --- | --- | --- |
| Scientific Scale | Wide-to-macro shot, continuous reference object and scale reveal | Astronomy, bodies, materials |
| Geographic Infographic | Regions highlight, pathways and causes shown on a grounded map | Geography, climate, migration |
| Anatomy Cutaway | Labeled isolated layers, plausible anatomy, internal camera | Brain, heart, respiratory system |
| Microverse Journey | Continuous scale transition with labeled magnification | Cells, DNA, microscopic science |
| Physics Simulation | Diagrams for forces, motion and modeled fields | Gravity, magnetism, waves |
| Exploded Mechanism | Disassembly along consistent axes, inspect, reassemble | Robots, satellites, machinery |
| Cause & Effect Puzzle | Distinct pieces shift and lock into a causal mechanism | Systems, processes, physics |
| Evolution Timeline | Time markers and branching relationships, not shape morphing | Prehistory, natural history |
| Alternate History | Source-grounded historical baseline vs explicitly labeled counterfactual | History and what-if scenarios |
| Exoplanet Ecosystem | Cohesive imagined world with clearly speculative biology | Alien life and planetary hypotheses |

An additional [Cosmic Scale SVG concept](gallery/13-cosmic-scale.svg) is available as an alternate visual study.

## Motion and quality principles

- Specify a strong camera move or object movement each scene; avoid slide-like dissolve-only transitions.
- Maintain **object identity, count, geometry, location, and continuity** across shots. Objects must not duplicate, teleport, flicker or morph unpredictably.
- Use real spatial cause and effect: the event is visible before the response and movement must follow plausible paths.
- In each 10-second clip, keep four scenes legible and ensure the transitions are intentional.
- Treat illustrations and SVG previews as *concept art*. Replace rough schematic anatomy with verified reference material before making detailed educational claims.
- For unsettled science, distinguish observed facts, models and speculation. Alternate histories and extraterrestrial ecosystems are hypothetical.
- Check diagrams, dates, labels, claims, audio rights, and original educational value before publishing.

## Scope

The cards in `README.md` link to static SVG assets in `docs/gallery/`. Rendering, animation presets, timelines, code examples and video export workflows would require separate implementation and testing. No change in this gallery update alters the original Bang Motion runtime or scripts.
